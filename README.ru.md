# Model Improvement Lab

[Архитектура проекта](docs/architecture.ru.md).

Версия 3.0.0. [English instructions](README.md).

> [!NOTE]
> **Экспериментальный выпуск для сообщества.** Этот выпуск предназначен
> для исследований, дообучения моделей и экспериментов со
> спекулятивным декодированием.

Model Improvement Lab — локальная лаборатория для запуска, дообучения и упаковки
моделей зрения, речи, музыки и draft-моделей. В проект входят готовые модели,
обучение с ограничением времени и подготовка пакетов для Hugging Face,
а также DFlash2 с D-PACE, офлайн-обучение EAGLE-3 и захват признаков из GGUF.

Для обучения нужны совместимые модель, runtime захвата и рецепт. Готовые
рецепты запускаются на Linux с CUDA. Демо, просмотр статуса и большинство
тестов работают на macOS.

## Что входит в пакет

- Зрение, распознавание речи, свободное описание музыки и аудио/текстовые векторы.
- Мультимодальное дообучение с продолжением и подготовкой пакетов для Hugging Face.
- Захват признаков и подсчёт токенов через совместимую сборку llama.cpp.
- Trainer с сохранением весов, optimizer, scaler и состояния генераторов случайных чисел.
- Функции потерь Uniform и D-PACE для обучения DFlash2.
- Офлайн-захват признаков, обучение EAGLE-3 и экспорт в GGUF с рецептом для V100.
- Контроллер с порционной обработкой признаков и ограничением рабочего места на диске.
- Проверка метрик через DeepSeek, журнал решений и изменение темпа обучения.
- Сравнение трёх режимов: без draft, родительский draft и новый кандидат.
- Тесты, синтетическое демо и примеры публичных датасетов.

В пакете нет весов, частных датасетов, рабочих логов и ключей доступа.
Веб-панель в этой версии не реализована.

## Быстрая проверка без GPU

Достаточно Python 3.10 или новее. Устанавливать пакеты и вводить API-ключ не нужно.

```bash
python3 coach.py demo --run-dir ../model-improvement-lab-demo
python3 coach.py status --run-dir ../model-improvement-lab-demo
python3 -m unittest discover -s tests -v
python3 coach.py privacy-check
```

Демо создаёт синтетические файлы вне папки исходников. Оно не обучает модель
и не обращается к DeepSeek. Если PyTorch не установлен, связанные с ним тесты
будут пропущены. Для повторного запуска демо выберите новую папку.

## Обучение DFlash2

Пошаговый порядок описан в [русской инструкции](docs/guide.ru.md).
Там есть сборка runtime, установка окружения, формат данных, настройка ключа,
подготовка, запуск, возобновление и сравнение результатов.
[Английская инструкция](docs/guide.en.md) содержит те же шаги.

Скопируйте `configs/example.json` в `configs/training.local.json` и укажите
свои пути. Относительные пути отсчитываются от папки файла JSON.
Для небольшого датасета используйте `configs/lite.example.json`.
В готовом сценарии DFlash2 команда `coach.py run` сама запускает захват признаков.
Для другой архитектуры целевой модели подготовьте совместимый захватчик
и рецепт DFlash2.

Чтобы включить D-PACE, задайте `"training_objective": "dpace"` до подготовки
нового запуска. По умолчанию действует `uniform`. В инструкции по DFlash2
описано, как D-PACE взвешивает ошибки токенов и селектора.

## Обучение EAGLE-3

`python3 coach.py eagle3 --help` показывает команды для захвата признаков,
обучения и экспорта. [Инструкция EAGLE-3](docs/eagle3.ru.md) показывает,
как запустить готовый рецепт Whittle на V100 через SpecForge и llama.cpp.

> [!IMPORTANT]
> EAGLE-3 обучается на заранее захваченных признаках целевой модели. Для
> готового рецепта выполните `eagle3 capture` перед `eagle3 train`. Для другой
> поддерживаемой модели захватите признаки самостоятельно и используйте
> подходящий [рецепт SpecForge](https://github.com/sgl-project/SpecForge/blob/main/docs/sections/basic_usage/training.md).

В ML-Docs описаны эксперимент D-PACE и формат признаков для EAGLE-3.
[ML-Docs](https://github.com/biscet/ML-Docs)

## Зрение, речь и аудиовекторы

Команда `python3 coach.py multimodal --help` открывает загрузку моделей,
проверку данных, инференс, дообучение с ограничением времени, продолжение
из checkpoint и подготовку пакета для Hugging Face. Первые рецепты поддерживают
LoRA для Qwen3.5-4B, Qwen3-ASR-0.6B и музыкальных описаний Music Flamingo,
а также контрастивное обучение проекционных слоёв CLAP.
Форматы данных и команды описаны в
[руководстве по мультимодальным экспериментам](docs/multimodal.md).

## Примеры датасетов

- [DFlash DeepSeek TraceMix](https://huggingface.co/datasets/biscet/DFlash-DeepSeek-TraceMix).
  Пример `deepseek` загружает основные task split. Пример `stage2` берёт отдельные
  272 обучающих контекста и основные validation/test для проверки.
- [DFlash ChatGPT TraceMix Lite](https://huggingface.co/datasets/biscet/DFlash-ChatGPT-TraceMix-Lite).
  Пример `lite` использует OpenMix. В исходном поднаборе нет отдельного test,
  поэтому загрузчик делит проверочные семейства между validation и test.

Здесь сохранены только ссылки, ревизии и настройки загрузки. Самих записей
в пакете нет. Команда `download-example` загружает их по отдельному запросу
пользователя. Готовые ответы из датасетов отбрасываются. Ответы, токены и признаки
для обучения даёт выбранная целевая модель.

## Что ещё нужно проверить

Переносимая версия контроллера проверяется CPU-тестами и тестами с подменой
внешних процессов. Backend обучения взят из существующей CUDA-реализации.
Полный GPU-прогон именно этого переносимого пакета ещё нужно выполнить.

Слои признаков, словарь и архитектура draft заданы в коде. Смена пути
`target_model` не делает произвольную модель совместимой. В примере разрешён
один полный проход; наставник может завершить работу раньше. Loss и prefix
не заменяют замер скорости и оценку качества ответов. Кандидат автоматически
не устанавливается в рабочий inference-сервис.
